# Color Literal

## Hexadecimal Colors

Shell interprets color constants as hexadecimal if they are preceded by `#`. A hexadecimal color is specified with: `#RRGGBB` or `#RRGGBBAA`, where the `RR` (red), `GG` (green), and `BB` (blue) and `AA` (alpha) hexadecimal integers specify the components of the color. All values must be between `00` and `FF`.

For example, `#0000FF` is rendered as blue, because the blue component is set to its highest value (`FF`) and the others are set to `00`.

There are 140 color names predefined under the `color` scope.
